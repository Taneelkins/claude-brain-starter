## How this works
1. **"What's next" → read this note**, then the project's plans note.
2. **Each entry = Goal + Read for scope + Next step.** Claude reads the scope pointers before acting, so there's no blind exploring.
3. **Statuses:** `next` (do now) · `in progress` · `untested` (built, needs checking) · `blocked` (waiting) · `parked` (later).
4. This table drifts fastest. Trust the per-project note; `/save` refreshes this table.
