> **Read this first, every session.** Pick the project, open its folder note, read ONLY the note you need. Don't explore the file tree from scratch.

## 🚦 How to use this brain
1. **Start:** read this note, then [[Playbook]], then the one project folder note that matches the task.
2. **Target:** follow the folder note's pointers straight to the right note or file. One targeted read beats ten exploratory ones.
3. **Never read generated folders:** `node_modules`, `dist`, `build`, `.git`, `.venv`, `.next`.
4. **Grow it:** run `/save` after each chunk of work. The brain only stays useful if it stays accurate.
